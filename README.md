# Classroom Seat Randomiser

A simple, single-page web tool for teachers to randomise seating, generate groups, and cold-call students.

## Features

- **Saved classes** — names are stored locally in your browser
- **Absent toggle** — click a name to mark a student absent; they're skipped when seating
- **Locked seats** — click any seat to lock a specific student to it
- **Undo / redo** — Ctrl+Z / Ctrl+Shift+Z, or use the buttons
- **Groups mode** — randomise into N groups or groups of size K
- **Cold-call picker** — random pick with optional no-repeats-until-everyone

## Running locally

Just open `index.html` in any modern browser. No build step required.

## Files

- `index.html` — markup
- `styles.css` — all styling
- `app.js` — all logic
